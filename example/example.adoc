This document shows how the AsciiDoc elements look with the default template of AsciidoctorJ PDF.
It was converted with `asciidoctorj -b pdf -a reproducible example.adoc`: AsciidoctorJ produced Typst, and Typst, running on the JVM as WebAssembly, produced this PDF.

== Text

A paragraph can contain *strong*, _emphasized_, `monospaced`, ^superscript^ and ~subscript~ text, #highlighted# text, and text with a role such as [.red]#red#, [.underline]#underlined# or [.line-through]#struck through#.
The typographic replacements apply: "`double quotes`", '`single quotes`', an em dash -- like this, an ellipsis... and (C), (TM), ->.

The characters that have a meaning in Typst are escaped: 2 * 3 = 6, $9.99, #hashtag, @mention, <tag>, [brackets], snake_case, ~/path and // not a comment.

Links can be external, like https://asciidoctor.org[Asciidoctor] or https://typst.app, internal, like <<lists>> or <<code,the section about code>>, or point to an inline anchor: <<anchor>>.
Footnotes are placed at the bottom of the page.footnote:[Typst lays out the footnotes.]

Use kbd:[Ctrl+Shift+P] to open the palette, click btn:[OK], or select menu:File[Export,PDF].

Line breaks are preserved +
when a line ends with a plus.

== Raw Typst

A passthrough block contains Typst code, for what AsciiDoc can't express:

++++
#align(center, grid(
  columns: 3, gutter: 8pt,
  ..range(1, 7).map(n => rect(width: 40pt, height: 24pt, radius: 3pt,
    fill: color.mix((rgb("#2156a5"), n * 15%), (white, 100% - n * 15%)),
    align(center + horizon, text(fill: white, weight: "bold", str(n)))))
))
++++

[appendix]
== The default template

The default rendering is defined by `asciidoctor.typ`.
A template given with the `pdf-template` attribute can redefine any of its functions, or style the native Typst elements with show rules.
